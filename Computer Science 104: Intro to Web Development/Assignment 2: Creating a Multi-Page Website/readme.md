# Assignment 2: AllStar Performance Lab — Multi-Page Website

## 📖 Overview
This project expands the original **AllStar Performance Lab** homepage from Assignment 1 into a fully responsive, multi-page website.  
The site includes **Home**, **Services**, and **Contact** pages, all linked through a consistent navigation bar that adapts to desktop and mobile screens.

The project applies **responsive web design**, **external CSS styling**, and **web accessibility standards** to ensure a user-friendly experience across all devices.

---

## 🎯 Learning Outcomes
This assignment demonstrates mastery of the following course learning outcomes:

- Construct simple web pages using **HTML** to create content and **CSS** to style it.
- Apply **responsive design techniques** (flexible grids, media queries, and mobile-first design).
- Identify and apply **web accessibility principles** following WCAG guidelines.

## 🌐 Key Features
### 1. Multi-Page Structure
- **Home** introduces the business, mission, and core services.
- **Services** details training packages, sport-specific programs, and FAQs.
- **Contact** provides a labeled form and contact details with semantic `<address>` usage.

### 2. Responsive Navigation
- A **CSS-only hamburger menu** appears on smaller screens.
- On desktop, navigation links display horizontally for quick access.

### 3. Accessibility Practices
- Semantic HTML5 structure using `<header>`, `<main>`, `<footer>`, `<section>`, and `<nav>`.
- **Skip link** for keyboard users (`Tab` key focuses the link first).
- **Alt text** for all images and proper `<label>`–`for` connections in forms.
- Visible focus indicators and high color contrast.
- Mobile-first design ensures compatibility with assistive technology.

### 4. External Styling
- All design and layout are controlled in **styles.css**.
- Includes CSS variables for colors, spacing, and typography consistency.
- Grid and flexbox utilities make the layout fluid and device-independent.

## 🧩 Accessibility & Responsive Design Validation
- Verified with the **W3C HTML Validator** and **CSS Validator** (no major errors).
- Tested with **WAVE Accessibility Tool** to confirm alt text, headings, and focus order.
- Manually tested for responsive behavior on mobile and desktop browsers.
